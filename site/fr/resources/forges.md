# Les forges logicielles

Une [forge logicielle](https://fr.wikipedia.org/wiki/Forge_(informatique)) est un service web qui permet d'héberger le code source de ses applications et de les partager facilement.

Ainsi, on peut développer ses applications en utilisant son ordinateur personnel, puis passer par l'une de ces forges pour les récupérer et les exécuter sur son smartphone ou sa tablette, avec [*Termux*](../termux) pour les modèles sous *Android* et [*iSH*](../ish) pour les modèles *Apple*.
