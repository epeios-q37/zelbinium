# *HTML* and *CSS*
    
[*HTML*](https://en.wikipedia.org/wiki/HTML) is a language used to detail the elements composing a graphical interface, with which [*CSS*](https://en.wikipedia.org/wiki/CSS) is associated to define the appearance of these elements.

To help you create your applications, you'll find an editor on this site that allows you to view on the fly the rendering of the *HTML*/*CSS* code you've entered, as in the [*Interface*](/en/tutorial/frontend) section of the [tutorial](/en/tutorial/).

There is a lot of documentation on *HTML* and *CSS*, both on the web (https://developer.mozilla.org/docs/Learn/HTML and https://developer.mozilla.org/docs/Learn/CSS, for example) and elsewhere. Note that many of these documentations will mention *JavaScript*, a language associated with web technologies of which *HTML* and *CSS* are a part. However, using *HTML* and *CSS* in *Zelibinium* does not require any knowledge of *JavaScript*.
